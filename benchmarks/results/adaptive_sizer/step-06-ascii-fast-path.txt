Date: 2026-09-02
Source: Captured from terminal results and EXPERIMENT_LOG.md during implementation.

IMPLEMENTATION
For ASCII input, production simhash lowercases once and hashes overlapping byte slices, avoiding Vec<char> construction and one temporary String per 4-gram. Non-ASCII input retains the original Unicode scalar-value implementation.

CORRECTNESS COVERAGE
- Empty, short, mixed-case, whitespace, punctuation, and control ASCII inputs.
- 448 deterministic random printable-ASCII strings, lengths 0 through 255.
- Accented Latin, lowercase-expanding Turkish I, German, Greek, CJK, emoji, and decomposed Unicode.
- Test-only copy of the pre-optimization algorithm used as the reference.
