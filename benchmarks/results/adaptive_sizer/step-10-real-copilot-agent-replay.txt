Task provenance
Copilot Auto completed three deterministic repair tasks. Each task required it
to run inspect_context.py, edit only the implementation, and run the supplied
test file. All task tests passed.

- median.json: fix even-length median; test_statistics.py passed; statistics.py changed.
- currency.json: fix negative-cent formatting; test_currency.py passed; currency.py changed.
- slug.json: fix punctuation and separator normalization; test_slug.py passed; slug.py changed.

The complete JSON arrays printed by inspect_context.py were captured from the
Copilot tool-result transcripts. benchmarks/scenarios/copilot_agent_tool_outputs.py
regenerates each array and rejects a SHA-256 mismatch.

Scope
The replay constructs SmartCrusher.without_compaction() to measure the
SimHash-dependent adaptive sampling fallback directly. It is not a claim that
every production live-zone result avoids SmartCrusher's lossless-first stage.
The default live-zone route is covered separately by step-07. No production
traffic telemetry was collected, so this evidence does not establish fallback
frequency in deployed workloads.

Command, run from a directory outside the source checkout:
  $LEGACY_PYTHON $HEADROOM_ROOT/benchmarks/copilot_agent_replay.py \
    --captured-corpus --warmup 50 --iterations 500 > legacy-replay.json
  $OPTIMIZED_PYTHON $HEADROOM_ROOT/benchmarks/copilot_agent_replay.py \
    --captured-corpus --warmup 50 --iterations 500 > optimized-replay.json
